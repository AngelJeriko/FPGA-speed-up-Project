01 · The Problem

Alignment is the workhorse — and the bottleneck.

BWA-MEM2 maps billions of short DNA reads to a reference genome. It's the standard tool, and it's CPU-bound.

End goal

Speed up alignment with dedicated FPGA hardware.

Short-term goal — this review

Get one real piece of alignment running on an actual FPGA — proving the whole path works end to end.

“Walk before we run —
correctness on hardware first, speedup second.”

02 · Where the time goes

We profiled the real thing, then picked one target.

Rather than guess, we measured actual BWA-MEM2 runs to find the hotspots — then chose the kernel that's cleanest to move to hardware first.

The pick

The Banded Smith-Waterman (BSW) kernel — self-contained, well-defined inputs and outputs, and the classic first candidate for hardware.

Honest scope

BSW alone is a modest slice of total runtime. This stage proves the platform, not the final speedup.

Why say this out loud: setting expectations now means no one is surprised later — first silicon is a correctness milestone, and the throughput story comes after.
03 · What we built

A DP cell, replicated into a systolic band.

We wrote the BSW kernel in SystemVerilog — one dynamic-programming “cell” replicated 160× so a whole diagonal band computes in parallel.

04 · What “Vivado simulation” did — part 1

Running the hardware as software, before any chip exists.

Simulation lets us execute the RTL design and check its behavior — the first of two things we needed to prove.

Bit-exact check

Fed the design the exact same inputs as real BWA-MEM2 and confirmed the outputs match bit-for-bit against captured golden results.

Mutation testing

Deliberately broke the design to confirm the tests actually catch bugs — a green test that can't go red proves nothing.

Payoff: bit-exact match on real data — and a genuine correctness bug found and fixed along the way.
05 · What Vivado did — part 2

Correct logic isn't the same as buildable hardware.

Simulation proves the logic. Synthesis proves it can actually become gates on the chip — and run fast enough.

Is it real hardware?

Vivado turns the RTL into actual FPGA logic and flags anything that can't be built — issues simulation happily passes over.
