# Presentation

Presenter-ready slide decks for project reviews.

## `fpga_bringup_deck.html`

A self-contained 10-slide deck covering: the acceleration goal, the kernel we
picked and why, what the Vivado work proved (simulation → correctness,
synthesis → buildability + timing), and the step-by-step plan to a first
hardware run of the banded Smith-Waterman kernel on the FPGA
(AWS f1.2xlarge / Xilinx VU9P).

**Viewing.** Open the file in any modern browser — no build step, no external
assets (all CSS/JS inline; safe to open offline or serve statically).

**Controls.**
- `←` / `→` (or space / PageUp-Down) — navigate slides
- `Home` / `End` — jump to first / last slide
- Bottom rail — click any tick to jump; touch-swipe also works
- Theme button (top-right) — cycle Auto → Light → Dark
